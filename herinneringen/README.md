# 📸 BPC on Tour – onze herinneringen

Deze map is het fotoarchief van de BPC on Tour-website.

## Foto's toevoegen
1. Maak in `herinneringen/` een nieuwe submap per uitje, bijvoorbeeld `ahrtal-2026`, `selectiedag-2026` of `ardennen-2027`.
2. Open de map in GitHub, kies **Add file → Upload files**, selecteer de foto's en klik op **Commit changes**.
3. De foto's verschijnen automatisch in het Fotoalbum op de website. Bij Coolify met werkende GitHub-webhooks wordt de website automatisch opnieuw gepubliceerd; de fotogalerij laadt de bestanden ook rechtstreeks van GitHub.

Gebruik bij voorkeur gecomprimeerde JPG/WebP-foto's (richtlijn < 2 MB per foto) met herkenbare namen.

**Privacy:** de website en dit GitHub-project zijn publiek. Upload uitsluitend foto's waarvoor de betrokken personen toestemming hebben gegeven. De website biedt op dit moment geen rechtstreekse beveiligde foto-upload vanuit de browser.
